Cluster Inference & Compute Radar

A distributed inference system for Kubernetes. A dispatcher splits a HuggingFace dataset into shards and runs them in parallel as worker pods in a Kubernetes Job; an aggregator collects results and throughput into Postgres.

Alongside it, a live "compute radar" graph visualizes nodes, pods, utilization, and job flow in real time. Runs entirely on a local kind cluster — no cloud account or GPU needed.

About

I like building things that run on more than one machine — and making what they're doing visible while they run.

My recent work centers on Kubernetes and data pipelines: batch inference across a cluster, Kafka streaming, and the tooling to watch it all happen. Before that, I spent time on machine learning, from computer vision for a drone capstone to regression modeling.

In my own time, I think about how to scale infrastructure and experiment with new ways to scale ML workloads. I also love reading through other people's GitHub projects to see how they've built things.
